MiniSite Studio

YouTube 예약 업로드 도우미

MiniSite Studio는 사용자의 PC에서 실행되는 로컬 영상 제작 도구입니다. 만든 세로형 영상(Shorts)을 사용자 본인이 소유한 YouTube 채널에 예약 업로드할 수 있습니다.

  • 모든 영상과 프로젝트 파일은 사용자의 PC에만 저장됩니다.
  • YouTube 업로드는 사용자가 OAuth로 직접 승인한 뒤에만 동작합니다.
  • 인증 토큰은 Windows 자격 증명 관리자에 보관되고, 연결을 끊으면 삭제됩니다.
