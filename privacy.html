MiniSite Studio 개인정보처리방침

시행일: 2026년 10월 25일

MiniSite Studio(이하 "앱")는 사용자의 PC에서 실행되는 로컬 영상 제작 도구로, 사용자가 만든 세로형 영상(Shorts)을 사용자 본인이 소유한 YouTube 채널에 예약 업로드하는 기능을 제공합니다. 이 문서는 앱이 어떤 정보를 어떤 목적으로 처리하는지 설명합니다.

1. 처리하는 정보

  • Google 계정 인증 정보: OAuth 액세스 토큰과 리프레시 토큰. YouTube 채널에 동영상을 업로드하려는 목적에만 사용하며, 사용자의 PC 운영체제 키체인(Windows 자격 증명 관리자)에만 저장됩니다.
  • YouTube 채널 정보: 연결된 채널의 이름과 ID. 업로드 대상 확인에만 사용합니다.
  • 업로드할 콘텐츠 정보: 제목, 설명, 태그, 공개 설정, 예약 시각 등 사용자가 앱에서 작성한 값.
  • 영상·음성 파일은 사용자의 PC(작업 폴더)에만 저장됩니다.

2. 이용 목적

  • 사용자가 승인한 YouTube 채널로의 동영상 업로드 및 예약 게시
  • 연결 상태 확인과 오류 안내

3. 보관 및 파기

  • 토큰은 연결을 끊으면 즉시 삭제됩니다(앱 설정 > 연결 끊기).
  • 그 밖의 데이터는 사용자의 PC에만 남으며, 개발자가 별도 서버로 전송하거나 보관하지 않습니다.

4. 제3자 제공

  • 앱은 사용자 데이터를 판매하거나 제3자에게 제공하지 않습니다. 데이터는 Google의 YouTube API Services로만 전송됩니다.

5. 이용자의 권리

  • Google 계정의 보안 > 타사 앱 액세스에서 언제든지 앱의 접근 권한을 취소할 수 있습니다.
  • 권한 취소 또는 연결 끊기 후에는 예약 업로드가 동작하지 않습니다.

6. 아동

  • 앱은 만 14세 미만 아동을 대상으로 하지 않습니다.

7. YouTube API Services 고지

  • 앱은 YouTube API Services를 사용합니다. 앱을 사용함으로써 사용자는 YouTube 서비스 약관에 동의하게 됩니다.
  • Google 개인정보처리방침이 적용됩니다.
